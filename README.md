## 🌟 Ключевые возможности

### 📁 Коллекции и Организация
- **Кастомные коллекции**: Создавайте тематические коллекции с выбором цветов и иконок (поддерживаются иконки Lucide и загрузка собственных изображений).
- **Быстрое создание коллекции**: Создавайте новую коллекцию прямо на лету в выпадающем списке при сохранении сниппета.
- **Мульти-файловые сниппеты**: Как в GitHub Gist — один сниппет может содержать несколько файлов с разным синтаксисом (например: `index.ts`, `schema.sql`, `docker-compose.yml`).
- **Теги и Избранное**: Быстрая группировка сниппетов по тегам и добавление в избранное в один клик.

### 🛡️ Безопасность и Приватность
- **Административная панель и закрытый доступ**: Публичная регистрация на странице логина отключена для безопасности. Все учетные записи создаются администратором системы в специальной панели с назначением ролей («Администратор» или «Пользователь»), возможностью блокировки доступа, смены паролей и удаления.
- **Умный первый вход (Local Admin)**: При чистом первом запуске под полями авторизации отображается подсказка для входа под локальным администратором (`admin@snippetvault.local` / `admin12345`). Как только создана хотя бы одна учетная запись кроме локального администратора, этот блок навсегда пропадает со страницы входа.
- **Изоляция данных**: Все сниппеты и коллекции строго привязаны к аккаунту владельца.
- **Ключи доступа (Passkeys / WebAuthn)**: Мгновенный беспарольный вход по биометрии (Touch ID, Windows Hello, Face ID) или аппаратному ключу безопасности.
- **Двухфакторная аутентификация (2FA)**: Защита аккаунта 6-значными кодами из приложений-аутентификаторов (Google Authenticator, Яндекс Ключ, Apple Passwords, Authy).
- **Шеринг по секретной ссылке**: Каждый сниппет имеет уникальный токен (`/s/:token`), позволяющий делиться кодом только с теми, у кого есть ссылка.
- **Безопасное управление паролями**: Раздельные блоки изменения пароля и профиля с валидацией.

### 🗄️ Резервное копирование и Экспорт/Импорт данных
- **Экспорт всей базы**: Скачивание полного архива всех сниппетов, коллекций и метаданных в структурированном формате JSON в один клик.
- **Экспорт отдельной коллекции**: Возможность выгрузить в JSON только выбранную коллекцию со всеми входящими в неё файлами.
- **Импорт и восстановление**: Быстрое восстановление данных из ранее созданных бэкапов SnippetVault.
- **Очистка базы данных**: Безопасная очистка базы сниппетов и кастомных коллекций с модальным окном подтверждения.

### 🎨 Интерфейс и Персонализация
- **Два режима отображения**: Переключение между визуальной сеткой карточек с превью кода и компактным табличным списком строк.
- **Персональные настройки интерфейса**: Выбор режима отображения по умолчанию (сетка или компактный список) и сортировки сниппетов во вкладке «Общие настройки».
- **Умное определение языка**: Автоматическое определение языка синтаксиса по расширению файла и коду сниппета при создании, с возможностью ручного выбора из 30+ языков.
- **Плавные анимации**: Продуманный темный интерфейс (Dark Theme) с плавной адаптивной анимацией переключения вкладок модальных окон.
- **Подсветка синтаксиса**: Поддержка 30+ языков (TypeScript, JavaScript, Python, Go, Rust, C++, C#, SQL, Bash, Dockerfile, YAML, JSON, Markdown, HTML, CSS и др.).
- **Command Palette (`Ctrl+K` / `⌘K`)**: Мгновенный полнотекстовый поиск по базе, коду, тегам и горячим клавишам без использования мыши.

### 🤖 Встроенный AI-ассистент
- **Автогенерация метаданных**: Анализ кода и автоматическое создание информативного названия, описания и тегов.
- **Объяснение кода**: Доступный разбор логики алгоритма, нюансов реализации и сложности.
- **Рефакторинг**: Оптимизация, повышение надежности и приведение к best practices.
- **Документирование**: Автоматическое добавление docstrings / JSDoc / комментариев с возможностью применить изменения прямо в редактор.
- **Поддержка любых провайдеров**: OpenAI (`gpt-4o-mini`, `gpt-4o`), Google Gemini (`gemini-1.5-flash`), а также локальные LLM (Ollama, LM Studio) через кастомный эндпоинт.

## 🐳 Развертывание на Synology NAS (DSM 7.2+)

Официальный Docker-образ опубликован в Docker Hub:
**`scfmcdck/snippet-vault:latest`** (или `scfmcdck/snippetvault:latest`)

### Вариант 1: Через интерфейс Container Manager (Рекомендуемый)

1. **Создайте папку для базы данных**:
   - Откройте **File Station** на вашем Synology NAS.
   - В общей папке `docker` создайте каталог `snippetvault`, а внутри него подпапку `data`:
     ```
     /docker/snippetvault/data
     ```
   *(В этой папке будет храниться SQLite база данных `snippetvault.db`. Все ваши данные останутся нетронутыми при обновлениях контейнера).*

2. **Создайте проект в Container Manager**:
   - Откройте приложение **Container Manager** в DSM.
   - Перейдите в раздел **«Проект» (Project)** слева и нажмите **«Создать» (Create)**:
     - **Имя проекта**: `snippetvault`
     - **Путь**: выберите созданную папку `/docker/snippetvault`
     - **Источник**: выберите **«Создать файл docker-compose.yaml»**
   - Вставьте конфигурацию:

```yaml
services:
  snippetvault:
    image: scfmcdck/snippet-vault:latest
    container_name: snippetvault
    restart: unless-stopped
    ports:
      # Замените первое число на любой свободный порт на Synology (например, 8585:3000)
      - "3000:3000"
    environment:
      - DATABASE_URL=file:/app/data/snippetvault.db
      - PORT=3000
      - HOSTNAME=0.0.0.0
      # Опционально: можно настроить AI прямо из веб-интерфейса в "Параметры -> AI Ассистент"
      - AI_PROVIDER=openai
      - AI_API_KEY=
      - AI_BASE_URL=https://api.openai.com/v1
      - AI_MODEL=gpt-4o-mini
    volumes:
      - ./data:/app/data
    healthcheck:
      test: ["CMD-SHELL", "wget --no-verbose --tries=1 --spider http://127.0.0.1:3000/ || exit 1"]
      interval: 20s
      timeout: 5s
      retries: 3
      start_period: 15s
```

3. Нажмите **«Далее»**, отметьте галочку **«Запустить проект после сборки»** и нажмите **«Применить»**.
   - Container Manager сам загрузит образ из Docker Hub, автоматически применит схему базы данных и запустит приложение.

### Вариант 2: Через SSH (Терминал)

```bash
# 1. Перейдите в каталог docker
cd /volume1/docker
mkdir -p snippetvault/data && cd snippetvault

# 2. Создайте файл docker-compose.yml и запустите сервис:
docker compose up -d
```

### Как изменить порт?
В строке `ports:` меняйте **только первое число**:
```yaml
ports:
  - "8585:3000" # Приложение будет доступно по порту 8585
```

### Доступ к сервису
Откройте в браузере: `http://<IP_вашего_Synology>:3000` (или указанный вами порт).

## 🐳 Быстрый запуск на любом сервере или ПК (Docker)

Запуск одной командой `docker run`:

```bash
docker run -d \
  --name snippetvault \
  --restart unless-stopped \
  -p 3000:3000 \
  -v $(pwd)/data:/app/data \
  scfmcdck/snippet-vault:latest
```

Или через `docker compose`:
```bash
docker compose up -d
```

## 🛠 Локальная разработка (без Docker)

Если вы хотите запустить проект локально в среде разработки:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/scfmcdck/snippet-vault.git
cd snippet-vault

# 2. Установите зависимости
npm install

# 3. Примените схему базы данных SQLite
npx prisma db push

# 4. Запустите dev-сервер (Next.js Turbopack)
npm run dev
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

## 🤖 Настройка AI Ассистента

Настройки AI можно задать как в переменных окружения, так и прямо в веб-интерфейсе через вкладку **«AI Ассистент»**:

1. **OpenAI** (по умолчанию: `gpt-4o-mini`):
   - Укажите ваш API ключ `sk-...`.
2. **Google Gemini** (модель: `gemini-1.5-flash`):
   - Укажите Google Gemini API ключ.
3. **Локальный Ollama / LM Studio**:
   - Base URL: `http://localhost:11434/v1` (или `http://host.docker.internal:11434/v1` при запуске внутри Docker).
   - Модель: `llama3`, `deepseek-coder`, `qwen2.5-coder` и др.
   - API ключ: не требуется.

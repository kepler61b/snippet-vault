# ⚡ SnippetVault

**SnippetVault** — современный веб-сервис для хранения, каталогизации, быстрого поиска и шеринга фрагментов кода (сниппетов) с поддержкой нескольких файлов в одном сниппете, подсветки синтаксиса, командной строки (`Ctrl+K`) и встроенного **AI-ассистента**.

Полностью упакован в **Docker** и запускается в один клик.

---

## 🚀 Ключевые возможности

- 📁 **Мульти-файловые сниппеты**: Как в GitHub Gist — один сниппет может содержать несколько файлов (например: `server.ts`, `schema.sql`, `docker-compose.yml`).
- 🎨 **Подсветка синтаксиса**: Поддержка популярных языков (TypeScript, Python, Go, Rust, SQL, YAML, Bash, Dockerfile, C++, Java и др.).
- ⌨️ **Command Palette (`Ctrl+K` / `⌘K`)**: Мгновенный поиск по всей базе сниппетов, коду, тегам и горячим командам без мыши.
- 🤖 **Встроенный AI-ассистент**:
  - **Автозаполнение**: AI анализирует код и автоматически генерирует емкое название, описание и теги.
  - **Объяснение кода**: Доступный разбор алгоритма, ключевых нюансов и сложности.
  - **Рефакторинг**: Оптимизация, повышение надежности и приведение к best practices.
  - **Документирование**: Автоматическое добавление docstrings / JSDoc / комментариев с возможностью применить изменения прямо в редактор.
  - **Поддержка любых LLM**: OpenAI (`gpt-4o-mini`, `gpt-4o`), Google Gemini (`gemini-1.5-flash`), а также локальных моделей через Ollama / LM Studio.
- 🔒 **Гибкая приватность и шеринг**:
  - `Публичный`: Доступен в общем списке.
  - `По секретной ссылке (Unlisted)`: Доступен только тем, у кого есть уникальный URL (`/s/:token`).
  - `Приватный`: Виден только владельцу.
- ⭐ **Избранное, теги и фильтры по языкам**: Быстрая фильтрация в сайдбаре по клику.
- 📋 **Быстрый экспорт**: Копирование сырого кода, скачивание отдельных файлов или копирование готового блока Markdown.
- 🐳 **Docker-Ready**: Полная упаковка в контейнер, SQLite в режиме WAL с сохранением данных в примонтированный том `./data`.

## 🐳 Быстрый запуск в Docker

Для запуска приложения требуется только установленный **Docker** и **Docker Compose**.

### 1. Клонируйте проект или перейдите в папку
```bash
cd SnippetVault
```

### 2. Настройте переменные окружения (опционально)
Скопируйте шаблон конфигурации:
```bash
cp .env.example .env
```
*(При необходимости укажите `AI_API_KEY` в файле `.env` или настройте его позже прямо в веб-интерфейсе через вкладку «Настройки»).*

### 3. Запустите контейнер
```bash
docker compose up -d --build
```

### 4. Откройте в браузере
Перейдите по адресу: **[http://localhost:3000](http://localhost:3000)**

> **Примечание:** База данных SQLite сохраняется на хост-машине в папке `./data/snippetvault.db`. Все ваши данные останутся нетронутыми при перезапуске или обновлении контейнера.

## 🛠 Локальная разработка (без Docker)

Если вы хотите запустить проект локально в среде разработки:

```bash
# 1. Установите зависимости
npm install

# 2. Инициализируйте схему базы данных SQLite
npx prisma db push

# 3. Запустите dev-сервер с Turbopack
npm run dev
```

Приложение запустится на [http://localhost:3000](http://localhost:3000).

## 🤖 Настройка AI Ассистента

SnippetVault поддерживает три режима работы нейросети:

1. **OpenAI** (по умолчанию: `gpt-4o-mini`):
   - Укажите ваш ключ `sk-...`.
2. **Google Gemini** (модель: `gemini-1.5-flash`):
   - Укажите Gemini API ключ.
3. **Локальный Ollama / LM Studio / Custom**:
   - Base URL: `http://localhost:11434/v1` (или `http://host.docker.internal:11434/v1` при запуске внутри Docker).
   - Модель: `llama3`, `deepseek-coder`, `qwen2.5-coder` и др.
   - API ключ: не требуется (или любой плейсхолдер).

> Настройки можно изменить в любой момент через иконку шестеренки **«Настройки»** в верхнем правом углу веб-интерфейса. Они сохраняются в локальной базе данных.

## 📂 Структура проекта

```
SnippetVault/
├── data/                      # Хранилище локальной базы SQLite (монтируется в Docker)
│   └── snippetvault.db
├── prisma/
│   └── schema.prisma          # Схема моделей Prisma ORM (Snippet, SnippetFile, Setting)
├── public/                    # Статические ассеты
├── src/
│   ├── app/
│   │   ├── api/
│   │   │   ├── ai/            # API эндпоинт для вызова LLM функций
│   │   │   ├── settings/      # API для сохранения/чтения настроек AI
│   │   │   ├── snippets/      # CRUD эндпоинты сниппетов и файлов
│   │   │   └── tags/          # Эндпоинт статистики тегов и языков
│   │   ├── s/[id]/            # Страница просмотра публичного сниппета по ссылке
│   │   ├── globals.css        # Стили Tailwind CSS и Prism Syntax Theme
│   │   ├── layout.tsx         # Главный лейаут с шрифтами Geist
│   │   └── page.tsx           # Основной интерактивный интерфейс приложения
│   ├── components/
│   │   ├── AIModal.tsx        # Модальное окно результатов работы AI
│   │   ├── CodeBlock.tsx      # Компонент отображения кода с PrismJS и строками
│   │   ├── CommandPalette.tsx # Командная строка Ctrl+K
│   │   ├── Navbar.tsx         # Верхняя панель управления и глобальный поиск
│   │   ├── SettingsModal.tsx  # Модалка настроек AI провайдера
│   │   ├── Sidebar.tsx        # Сайдбар с фильтрами, тегами и языками
│   │   ├── SnippetCard.tsx    # Карточка сниппета в сетке
│   │   ├── SnippetEditorModal.tsx # Редактор с поддержкой нескольких файлов
│   │   └── SnippetViewModal.tsx   # Детальный просмотр и быстрые действия
│   ├── lib/
│   │   ├── ai.ts              # Логика интеграции с OpenAI, Gemini и Ollama
│   │   ├── db.ts              # Prisma Client с поддержкой SQLite WAL
│   │   ├── languages.ts       # Справочник языков, расширений и цветов
│   │   └── seed.ts            # Демонстрационные сниппеты при первом запуске
│   └── types/
│       └── snippet.ts         # TypeScript интерфейсы
├── docker-compose.yml         # Конфигурация запуска Docker Compose
├── docker-entrypoint.sh       # Стартовый скрипт инициализации БД и запуска
├── Dockerfile                 # Многостадийный (multi-stage) Docker-образ
├── next.config.ts             # Конфигурация Next.js в режиме standalone
└── package.json
```
